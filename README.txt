# Student Management System in C++

## 📌 Project Description

The **Student Management System** is a simple C++ console-based project used to manage student information. It allows the user to add, display, search, update, and delete student records.

## ✨ Features

* Add student details
* Display student details
* Search for a student
* Update student information
* Delete student records
* Menu-driven program

## 🛠️ Technologies Used

* **Language:** C++
* **Concepts:** Classes, Objects, Constructors, Functions, Encapsulation, Loops and Conditional Statements
* **Platform:** Linux / Windows

## 📂 Project Structure

```text
Student-Management-System-Cpp/
│
├── Student.cpp
└── README.md
```

## ▶️ How to Run

### Compile

```bash
g++ Student.cpp -o student
```

### Run

```bash
./student
```

## 🎯 Objective

The main objective of this project is to learn and implement **basic C++ and Object-Oriented Programming concepts** by developing a simple student record management system.
